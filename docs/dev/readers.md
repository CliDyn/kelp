## readers/
Registry in `__init__.py`: `get_reader(name)` auto-imports known modules. Shared helpers: `_detect_engine(path)` (`"zarr"` for `.zarr` paths or dirs with `.zattrs` (v2) or `zarr.json` (v3, since 2026-10-04), else `"netcdf4"`), `extract_time_info(ds) → (times_sec, file_dt)` (datetime64 / cftime / numeric-with-units; `(None, None)` if uninterpretable), `time_axis_epoch(ds) → ("seconds since YYYY-MM-DD hh:mm:ss[.f]", calendar) | None` (same origin and decoding branches; None for a bare unit, an index axis, NaT, or an axis xarray cannot decode — the output then gets `units = "seconds"` + `NO_EPOCH_NOTE` as `time_origin`), `_read_kh_fields` (spatial Kh for em/m1, layout auto-detected).

Reader interface (all `@staticmethod`, register with `@register("name")`):
```python
load_mesh(mesh_cfg[, mode_cfg=None]) → Mesh       # mesh_cfg.meshpath; mode_cfg passed only when the signature takes it (healpix)
open_dataset(path, v_path=None, w_path=None, mode_cfg=None, **extra) → xr.Dataset
                                                 # run_tracking ALWAYS passes mode_cfg=; extra: diffusion= (fesom2, active Az), eta_path= (healpix, data.ncinput_eta set)
read_velocities(ds, timestep, mesh, mode_cfg=None, diffusion=None, sample_vars=None, velocity_float32=False) → VelocityField
read_scalar_fields(ds, timestep, mesh, varnames, mode_cfg=None) → dict[str, ndarray]  # optional; node-based, trimmed to mesh.sigma
probe_uv_layout(ds, mode_cfg, mesh) → "node" | "element"   # optional; metadata-only, the pre-writer fail-fast
```
- `read_scalar_fields`: FESOM2 `nz1`→K-1 / `nz`→K trim, 2D-mode level pick like velocities; FESOM-C sigma dims + **node-aware** 2D reduction `_reduce_scalar_to_2d` (`_reduce_to_2d` is element-hardcoded — never reuse it for node fields). Missing/element-sized vars → ValueError (fail-fast at run_tracking startup).

- **fesomc.py** 3-D W (2026-09-23, final form after the review of PR #102): tracks with FESOM-C `w` = `Wvel` (positive-UP flux through the sigma INTERFACES, 0 at surface and bottom, `fv_3D_vel.F90:vert_vel_sigma`); the reader returns `W = −Wvel` (sign via `resolve_w_sign`, default up) and nothing else; the SIGMA STEP integrates the particle's sigma fraction `s = z/H_p`, `ds/dt = W/H_p`, placing every RK stage at `z = s·H_p(x_stage, t_stage)` and the end at `s_new·H_p(x_new, t_end)` (`integrators._sigma_col_H`/`_eta_blend`/`_sigma_end_eta`/`_EtaView`, `sigma_eta_start`/`sigma_eta_end` kwargs: the tracking layer supplies the surface at the step's start and end from ONE function of time (`tracking._eta_at_time`: PCHIP where a stencil exists and PCHIP is on, else the linear payload blend; discrete mode: the next record as the end) — end of a step and start of the next are bit-identical, s continuous across steps (also across steady-fallback steps between PCHIP steps) and a resumed run reproduces the continuous one (TestSigmaRestartIdentity); a mutable carry of the previous end surface broke that (1 ulp); layers/clamp/kicks use the same `H_p` via `H_col`/`H_particle`/`sigma_col`) — exact for moving surface + sloping bottom + uniform σ̇ (TestSigmaIntegration). `vel_w` on sigma meshes = the dia-sigma flux positive down. `w_cart` REFUSED (lacks the dia-sigma part). History: w_cart as W → centred η_t in W → start-of-step depth scaling → s-integration (docs/vertical.md §3).
- **fesomc.py**: mesh from a single NetCDF (`lon/lat/depth/nv` 1-based 4-column, `lon_elem/lat_elem`, `sigma_lev`); `_sanitize_connectivity` → 0-based/-1-fill/dedup; `_reduce_to_2d` picks a sigma layer or sigma-weighted vertical mean; custom var names via `mode_cfg.var_u/...`, fallback `u2d`→`u`; `u2d_puls`/`v2d_puls` if Vpuls. **Rejects** `mesh.rotation` (ValueError, no vector-rotation path); near-pole warning at `max|lat| > 88°` **without** the rotation hint.
- **fesom2.py**: mesh from ASCII dir (`nod2d.out`/`elem2d.out`, arctan2 circular-mean centres), NetCDF mesh diag — **convention-agnostic** via `_resolve_mesh_vars` (still requires the `nod_in_elem2D(_num)` table — a plain UGRID file without it raises KeyError; the Zarr path rebuilds it) (handles `lon`/`lat`+`elements`+`nz`; the older core2 packed `nodes` (radians) + `elem` (3,E) + `zbar` (neg.) form; and UGRID `lon`/`lat`+`face_nodes` (E,3)); reads by variable NAME not dim name, orients connectivity to (E,3), `abs()`-es z; precomputed `nod_in_elem2D(_num)`, `zbar_n_bottom` (11.5M-node global mesh loads in ~5 s (development measurement, not recorded in the repository)) — or Zarr (as produced by `utils/extract_fesom_region.py`) — auto-detected from `meshpath`. Velocities from a single file or a dir of `u*/v*` (+ `ssh*`, `w*`); an attached `ncinput_v`/`ncinput_w` and the dir's `v*`/`w*`/`ssh*`/extras are re-positioned onto the u file's records by `readers._align_onto_time_axis` (instants compared via `_time_instants`: datetime64 ≡ standard cftime, CF-numeric decoded, bare units scaled to integer µs; `_match_records`: identical axes pair by position (repeats too), else refuse invalid/one-sided-repeated stamps, no common stamp, and — numeric kinds only — a record inside u's span that is not a u record; dates accept a finer superset with a RuntimeWarning (sub-sampled; next to time means the values are single instants); v must cover all u records, W may cover a CONTIGUOUS block (`allow_missing`, lazy dask NaN fill elsewhere; a hole inside W's range = another cadence → refused; `read_velocities` refuses an all-NaN W record, `_VelCache._load_window` re-raises only for the requested index), no time dim → refused; a non-fitting W (dir `w*` or single-file `ncinput_w`) raises in 3-D or without mode_cfg and is skipped with a RuntimeWarning in 2-D; dir: non-fitting `ssh*`/extras skipped with a warning, partly covering ones attached with a warning naming the NaN records (`warn_missing`), opened files closed on refusal; dir (non-Zarr) `ncinput` + `ncinput_v/w` → warning, ignored) — xarray attaches by label and used to pad NaN (a reconstructed W came out all-NaN, 2026-10-04; FESOM-C's separate v/w merge uses the same helper; `_require_same_time_axis` = strict equality for position-paired inputs, e.g. reconstruct_w's v/ssh/ALE-w); ssh var names `ssh/eta/zos`; 3D mode (`Fdrift3D=True`) keeps depth dims and reads W (`w/wo/wvel`) — **negated** (FESOM2 `w` is positive UP, `oce_ale.F90:vert_vel_ale`; zstar = velocity through the moving interfaces → tracks the zstar depth: rate error η/H (≈1e-4 deep, 1–2 % on shelves; can accumulate if w and η correlate), depth offset from physical ≤ |η|) via `readers.resolve_w_sign(da, mode_cfg, family_default)`: `mode.w_positive` up|down > CF `positive` attr > CF `standard_name` (upward_/downward_) > family default (fesom2/fesomc/healpix `up`). Until 2026-09-23 NO reader converted — every FESOM2/HEALPix 3-D run moved vertically the wrong way (`tests/test_w_sign_contract.py` pins the sign against EqPac upwelling on real data). **Multi-year directory** (`<var>.fesom.<year>.nc`, e.g. core2 multi-decadal output): when `open_dataset` gets `mode_cfg` and EITHER configured velocity var's EXACT glob `<name>.fesom.<YYYY>.nc` matches ≥1 yearly file (`_is_exact_layout`, single-year dirs included; `_parse_year` requires the tail to be exactly `<YYYY>.{nc,zarr}`), it assembles the family from `mode.var_u/var_v/var_w/var_eta/sample_vars` (exact tokens → no `uice`/`unod`/`uwind` pollution) and concatenates all years **lazily** via `xr.open_mfdataset(combine="by_coords")` + `xr.merge(join="exact")` (per-file `seconds since <year>` epochs decode to one monotonic axis, validated strictly increasing; mixed cadence, e.g. monthly `u` vs daily `unod`, → `ValueError`; non-consecutive years → RuntimeWarning). Non-exact dirs (`u.nc`/`v.nc`) and single combined files keep the broad-glob path (back-compat). **Limitations**: multi-year exact mode assembles the velocity/eta/`sample_vars` family **plus `diffusion.var_az`** (threaded via `open_dataset(..., diffusion=)` by tracking, fesom2+active-az only) — `beaching.dry_mask_var` and spatial-diffusion Kh vars are still NOT globbed in multi-year mode (use single-year/pre-concatenated input for those); `_load_mesh_zarr` is NOT convention-agnostic (NetCDF only). Needs `dask`. `mode_cfg` threaded from `tracking.py`/`cli`; `read_velocities`/`read_scalar_fields` unchanged (`.isel(time=t)` on the dask-backed merged dataset). u/v var names honour `mode.var_u`/`var_v` (e.g. `unod`/`vnod`) before `u`/`v`; `uv_layout` auto-detected per variable (`_detect_field_layout`, u/v must agree); `probe_uv_layout` classifies the layout from dims/sizes only (metadata, no data load) for the pre-writer fail-fast. FESOM-C node-layout layered u/v use a node-aware 2D reduction (the element-hardcoded reducer can't serve node fields). **Rotation** (`mesh.rotation`; the healpix reader has its own `_apply_rotation` — see its bullet): `_resolve_rotation_angles` → `_apply_mesh_rotation` computes per-carrier vector factors FIRST from the **geographic** carriers, then rotates nodes+centres **AS POINTS** (centroid not rotation-equivariant → not recomputed); `read_velocities` applies the 2×2 factor map (`u'=c·u−s·v`, `v'=s·u+c·v`) per `uv_layout`, scalars (W/eta/Kh) pass through. `_warn_near_pole_fesom2` (`POLE_WARN_LAT=88`): degeneracy warning recommending `mesh.rotation` when rotation OFF, exact-pole-node warning when ON.
- **healpix.py** (docs/healpix.md; Phases 1–4 shipped — 2-D + 3-D, direct whole-store + extracts): `build_healpix_dual_mesh(nside, *, order, wet_mask, depth, z_levels, …)` → mixed tri/quad `Mesh`: nodes = wet pixel centres (⇒ node layout, `uv_interp: barycentric` REQUIRED), elements = corner dual cells built **integer-exactly** from `healpy.get_all_neighbours` slots (edge nbrs = SW/NW/NE/SE, corner diagonals = W/N/E/S, `-1` diagonal = the 8 valence-3 vertices → triangle; min-owner dedup; (owner, corner) sort ⇒ block_size-independent). All-wet globe: exactly 8 tris, `E = npix + 2` (self-checked at build), valence 4, χ=2. Lazy healpy import; ring input reordered to NEST; `_healpix_node_pix` (NEST) + `_healpix_data_idx` (store order) stashed for data compaction; int32 guard at nside ≥ 16384. `@register("healpix")` **HealpixReader**: mesh derived FROM the data store (`meshpath` = the u/v store; nside/order from `crs` attrs, `mesh.healpix_zoom` fallback; wet = finite u∧v at t=0 on the TRACKED level — `run_tracking`/CLI thread `mode_cfg` into `load_mesh` by signature inspection, so `var_u`/`var_v`/`sigma_layer` shape the mask; land must be NaN-encoded, a `deptho` var refines `wet &= deptho>0`; `mesh.crop_bbox [W,E,S,N]`, W>E = dateline, span ≥360° = lat band; bathymetry: `deptho` var → `mesh.levels` (aux3d path or inline metres) × deepest-finite-level (named-dim reduce) → zeros). Carriers: plain Zarr / NetCDF / **kerchunk `*.parq|.parquet|.json`** (fsspec reference + lazy gribscan codec + the `_install_reference_na_shim` null-ref guard; needs dask). **ng5 two-store recipe**: u/v from the 3-D store (surface; `mode.sigma_layer` picks), ssh via `data.ncinput_eta` or the auto-derived `3D`→`2D` filename sibling; time axes validated equal. Aliases `avg_uoe`/`uo`/`u` etc., `mode.var_*` overrides fail loud when absent. Fail-fasts: `ncinput_v`, `ncinput_w`, zoom mismatch mesh↔data. **`mesh.rotation` SUPPORTED (2026-08-16)**: pure runtime transform (HEALPix remap = geographic east/north, unlike model-native fesom2) — `_apply_rotation`: per-node tangent factors from GEO pixel centres (`rotate_vectors`), nodes+centres rotated as points, `build_search` REBUILT on the rotated chart, convexity NOT re-validated (the check is rotation-invariant); guards: wet element straddling a rotated pole → ValueError (containment chart would lie; pick angles with poles on land — 'fesom2' preset = Greenland/E-Antarctica, CORE2-twin wet max |rot lat| 85.3°), wet nodes >88° rotated → one-time warn; read_velocities applies u'=c·u−s·v per node (2-D and 3-D broadcast); w/eta/scalars pass through; transpolar great circle machine-precision-pinned; rotated CORE2-z6 PASSES the density certificate → fused-bary kernels engage (geo frame is denied). **em/m1 spatial Kh SUPPORTED on pixels** (2026-08-16): `_read_kh_pixels` reads `Kh_zonal`/`Kh_meridional` (or `diffusion.var_kh_*`) from the SAME store, pixel-space → node compaction like u/v (the shared `_read_kh_fields` size-detection cannot serve full-pixel arrays), `kh_layout="node"`; wet-NaN Kh zeroed + one-time warn; vars absent → kh None (split_rk kick raises its clear ValueError, fesom2 parity); split_rk only — combined (em/m1+euler) stays impossible (the `uv_interp != "leastsq"` guard of `_apply_combined_em_step` fires first, node-layout guard behind it); negative Kh rejected (shared contract); extracts carry Kh only when listed under `variables:`. - **structured.py** (foundation, TODO 4.6): `build_structured_mesh(lon2d, lat2d, wet_mask, …)` maps any logically-rectangular (curvilinear/regular) grid onto an unstructured **quad** `Mesh` — nodes = wet cell-centre (T) points **referenced by ≥1 fully-wet quad** (orphan wet cells with no fully-wet quad — 1-cell channel, ragged coast, diagonal-only island — are EXCLUDED: they'd be dead-end nodes → false OUTSIDE), elements = quads of 4 logically-adjacent T-points kept iff all 4 wet (land corner → quad dropped = coastline). Stashes `mesh._structured_shape=(ny,nx)` + `mesh._structured_node_id` ((ny,nx)→node id, −1 land **or orphan**). `c_grid_to_t(u_faces, v_faces, node_id)` averages Arakawa-C faces → T-points (node layout; **non-finite (NaN/`_FillValue`) faces → 0** before averaging, so a masked land face can't poison coastal wet T-points); `field_to_nodes(field2d, node_id)` compacts a T-point scalar (eta/temp). Model-agnostic — adapters feed it.
- **nemo.py** (`@register("nemo")`, TODO 4.6 v1 = **2D, E/N-aligned grids only**): NEMO C-grid output → `structured.build_structured_mesh`. `load_mesh` reads `nav_lon/nav_lat` + `tmask` (surface) from `mesh.meshpath` (mesh_mask/domain_cfg; all-wet if no mask). **Alignment fail-fast**: NEMO grid_U/grid_V are along the LOCAL grid axes, not geographic E/N; v1 uses them as E/N, valid only on an aligned grid, so `load_mesh` computes the max i-axis-from-east / j-axis-from-north deviation (`_max_axis_misalignment_deg`) and raises `NotImplementedError` if > `_ALIGN_TOL_DEG`=2° (skewed/curvilinear/ORCA → needs vector rotation, the next PR). `open_dataset` assembles grid_T (`ssh`+sampled T-scalars) + the **derived** grid_U/grid_V siblings (swap the `grid_T` token in the basename; grid_V also via `ncinput_v`; **grid_W/`ncinput_w` are reserved for the 3D follow-up and inert in v1** — `open_dataset`'s `w_path` is unused and `w` is always None) into ONE ds (vars `u/v/ssh/…`, dims renamed `time_counter→time`, `depth*→z`). **Time-axis check**: grid_U/grid_V must share grid_T's time axis — validated by record count + exact timestamps with an all-or-none coordinate rule (a coord on one side but not the other → `ValueError`, never graft); when no file carries a decodable time coordinate, the merged "time" dim gets an integer fallback coord (so `ds['time']` always exists downstream; a plain arange reads as "no real time" → explicit `numerics.dt` required). `read_velocities` → `c_grid_to_t` → **node-layout** u/v (⇒ run needs `uv_interp: barycentric`; node+leastsq fails fast), `ssh`→eta (non-finite ssh zeroed); honours `velocity_float32`. `probe_uv_layout(ds, mode_cfg=None, mesh=None)→"node"` (pre-writer fail-fast). Var aliases (`uo/vozocrtx/…`, `vo/…`, `ssh/zos/…`) + `mode.var_*` overrides (a set-but-absent `var_u`/`var_v`/`var_eta` → `KeyError`, never a silent alias fallback). **Fail-fast guards** (each a staged follow-up, never a silent wrong answer): skewed grid (above), `mesh.rotation`→ValueError, `Fdrift3D`→NotImplementedError (open + read), `mode.sigma_layer` other than 0/null→NotImplementedError (open + read; v1 always reads the surface level, the layer was ignored silently until 2026-10-04), `em`/`m1` diffusion→NotImplementedError. **Out of scope (staged)**: **vector rotation** (grid-relative u/v → E/N; the gate for true curvilinear + global ORCA) — NEXT PR; global ORCA north-fold seam + E-W periodicity; 3D (`deptht/e3t`/partial cells/W); offline `utils` converter (same foundation); exact C-grid scheme. Exact C-grid → Parcels-style separate interpolator.
