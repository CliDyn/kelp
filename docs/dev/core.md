## core/particles.py
- `ParticleStatus`: ALIVE=1, BEACHED=2 (assigned by the beaching hook, TODO 2.2; **reversible** — BEACHED↔ALIVE via resuspension, the only status that flips back; NOT_RELEASED → ALIVE also flips once, at release), OUTSIDE=3, NOT_RELEASED=4 (delayed release, TODO 2.5 — frozen until its release step; excluded from `alive_mask` so integrators skip it; flips to ALIVE via the activation hook, NOT a death). `ParticleState.release_step: Optional[(P,) int32]` rides like `failure_reason` (None = no delayed release; flows through replace/snapshot, checkpointed).
- `FailureReason` (IntEnum, int8): NONE=0, INTERPOLATION_FAILED=1, OUT_OF_BOUNDS=2, SURFACE_HIT=3 (reserved), BOTTOM_HIT=4 (reserved). **Sticky**: set once when the particle dies; only the beaching hook clears it (on its on_failure remap to BEACHED and on resuspension), so the field keeps cause-of-death semantics. Opt-in via `mode.track_failure_reason` (default False → the array stays None). Populated by **ALL** integrator paths since 2026-08-16 (candidate 7): the unfused paths via `_update_failure_reason`, the fused kernels via an int8 `fr_out` scratch (`_FR_INTERP`/`_FR_OOB` stamped at the failure branches) merged by `_merge_fused_failure` — opt-in as before (a None array stays None). Helpers: `failure_reason_to_string`, `count_failure_reasons`.
- `ParticleState`: required arrays `lon, lat, z, status, nearest_node`; optional `u, v, w` (last evaluated velocity, set by integrators, flows into trajectory output as `vel_u/vel_v/vel_w` — masked NaN for output where not ALIVE through the step, see `core/release.py`), `failure_reason`, `elem` (carried containing element, int32; `None` = edge-walk tracking off, byte-identical; rides replace/snapshot, checkpointed as `restart_elem`), and `release_lon/release_lat/release_z` (output format 2: `(P,)` f8 release position in the MESH frame; filled by `run_single_realization` from the initial state when `start_step_i == 0` and None — seeds after the periodic fold, NOT_RELEASED keep their seed; checkpointed as `restart_release_*`, attached by `load_restart`, so chain segments carry them without driver changes; `None` = unknown, a pre-format-2 restart). `_OPTIONAL_ARRAYS` lists every optional per-particle array — extend it when adding one.
- Methods: `.alive_mask`, `.replace(**kw)` (immutable update), `.snapshot()`, `.subset(index)` (new state with EVERY per-particle array — required and `_OPTIONAL_ARRAYS` — sliced by an index array / bool mask / slice, None stays None; use it to split a state, e.g. the pulsed restart-split: a field-by-field slice silently misses fields added later — the review BLOCKER that introduced it), `.save/.load` (whitespace `lon lat [depth]`), `.from_grid(...)`, `.from_around_point(...)`. `make_state(lon, lat, z=None)`, `load_particles(path)` (back-compat wrapper).

## core/release.py — delayed / staggered release (TODO 2.5)
Freeze-until-step (pre-allocate all particles; not-yet-released ones are `NOT_RELEASED`, excluded from `alive_mask`) instead of growing the pool. Release time = OFFSET seconds from run start → `release_step = round(release_sec/dt)`; activation is `global_step_i >= release_step` (direction-agnostic — the run increments `step_i` even backward). `build_release_state(lon, lat, z, release_sec, *, n_pulses, pulse_interval, dt, start_step_i)` replicates the seed set into pulses (pulse `p` adds `p*pulse_interval`) + per-particle `release_sec` column (composed additively); returns a plain `make_state` (release_step=None) for the trivial schedule (byte-identity). `activate_released(state, global_step_i)` flips `NOT_RELEASED→ALIVE` (same object when none/None). `mask_dormant_for_record(state, sampled)` NaN-masks dormant `lon/lat/z`+`vel`+`sampled` for OUTPUT only (status stays NOT_RELEASED; same objects when none dormant). `mask_inactive_velocity(state, prev_status)` (output format 2) NaN-masks `u/v/w` for OUTPUT where `prev_status != ALIVE` (post-activation, pre-step) OR `state.status != ALIVE` (post-step, post-beaching hook) — dying record, dead/beached/outside/dormant particles, a particle resuspended this step (the kernel skipped it and wrote 0); copies, same object when nothing to mask, `w` None stays None. Release instant written to the output: `release_time = T_g0 + max(release_step, 0)·dt·direction` (the ROUNDED schedule; a never-activated particle's lies after the last record). `read_seeds_with_release(path)` reads `lon lat [depth] [release_sec]`.

## core/particles_gen.py
- `generate_grid(mesh, nx, ny, margin)` — regular grid over mesh extent, filtered to in-mesh; `margin` = fraction shrunk inward per side.
- `generate_around_point(mesh, lon0, lat0, n, radius_km, seed)` — uniform random in a circle, metric-scaled (`cos(lat)`) so it is circular in physical space.
- `_filter_to_mesh` raises `ValueError` if no candidates fall inside the mesh.

## core/io.py
- `VelocityField`: `u`, `v` element-based (`(E,)` 2D, `(K-1, E)` 3D); `eta` node-based `(N,)`; `w` node-based **at interfaces** `(K, N)`, None for 2D; optional `kh_zonal`/`kh_meridional` (`(N,)` or `(E,)` per `kh_layout="node"|"element"`) — all three Kh fields must be set together (post-init validation). `uv_layout: "element" | "node"` — mesh location of `u`/`v` (node = FESOM2 `unod`/`vnod`); validated in `__post_init__`, lerp raises on mismatch.
- `.lerp(other, alpha)` — temporal interpolation. Lerps Kh too when both sides carry it; raises on layout/shape mismatch; returns `kh=None` when only one side has it. Array blends go through `_blend` — numba `prange` kernel for large C-contiguous float64 (same-shape only; anything else → the numpy expression), bit-identical to numpy for finite values; broad import-except keeps `core.io` importable on numpy/numba binary mismatch.
- `LazyLerpField(vel_a, vel_b, alpha)` — duck-typed lerp VIEW: each field `_blend`s on FIRST access and caches (`.w` answers None for free when either parent lacks it — `_is_3d` probe stays cheap in 2D). `.vel_a/.vel_b/.alpha` expose the raw pair for the fused tinterp dispatch; `.lerp()` materializes then delegates (unfused `_make_stage_vels`/`_pick_kh_eval_vel` keep working). `_build_vel_payload` returns it between snapshots — consumers pay only for fields they read (beaching → eta only, sampling → scalars+eta; fused 2D kernels → nothing).
- `scalars: Optional[Dict[str, ndarray]]` — node-based sampled fields (`(N,)`/`(K-1,N)`/`(K,N)`), attached by `read_velocities(sample_vars=...)`; lerped only when both sides carry identical keys (key/shape mismatch raises); empty dict normalized to None in `__post_init__`.
- `az: Optional[ndarray]` — vertical diffusivity `(K, N)` at interfaces (same layout as `w`), read when `diffusion.var_az` set (TODO 2.2b); lerped when both sides carry it, dropped to None one-sided, shape mismatch raises; `LazyLerpField` lazy-blends it (`_LAZY_FIELDS`) and validates shapes at build.
- `uv_vertical: "layer" | "level" | "layer_linear"` (2026-10, depth-linear u/v; `numerics/vertical_uv.py`, docs/vertical.md §2.1) — vertical placement of `u`/`v`: `"layer"` (default; `(K-1, ·)`, piecewise constant per layer), `"layer_linear"` (`(K-1, N)` or `(K-1, E)` layer centres read linearly in depth; what `mode.uv_vertical: linear` makes of a layer field) or `"level"` (`(K, N)` on the levels, linear in depth). `__post_init__` → `_check_uv_vertical(u, w, uv_layout, uv_vertical)`: a 2-D field (`u` 1-D) must be `"layer"`; `"level"` needs `uv_layout="node"` WITH OR WITHOUT `w` (level data sit on the nodes' levels); `"layer_linear"` takes node or element layout (element layout: FESOM2 or FESOM-C `u`/`v`, read on the element table, [numerics.md](numerics.md)); rows are checked against `w` only for 3-D fields (`u` 2-D and `w` present): `"layer"`/`"layer_linear"` need `K-1`, `"level"` needs `K` — a FESOM2 field with u/v on `K` rows used to run on its first `K-1` rows and now raises here.
- `_dl_token` (dataclass `field(init=False, compare=False, repr=False)`, default None) — the depth-linear record check's stamp: the `DepthPoints` object of the mesh table the field passed (`check_depth_linear_record`; `is_checked` compares by IDENTITY). Every rebuild through the constructor (`dataclasses.replace`, `_assemble_vel` of the shared cache, `materialize` before it copies the token back) drops it; `lerp`, `LazyLerpField.__init__` and `reconstruct_pchip` keep it via `_shared_token(*parents)` — the parents' token only when ALL hold the SAME object, else None. Mixed placements are refused at every rebuild site by `_require_same_uv_vertical(site, *placements)` (message lists every placement in input order); `LazyLerpField` carries `uv_vertical` and `_dl_token` as plain attributes (never lazy — `__getattr__` raises for unknown names, so a placement read never blends).

## core/rotation.py — Euler rotated-frame primitives (pole-safe tracking)
- `FESOM2_ANGLES = (50, 15, -90)` (deg) — FESOM2's own frame, pole on Greenland; reconstructs the model's `elem_area` to machine precision. `euler_matrix(α,β,γ)` → `(3,3)` R, convention `v_rot = R @ v_geo`, inverse `R.T`.
- `rotate_lonlat`/`unrotate_lonlat` — point maps (lon/lat→xyz→R[.T]→lon/lat, wrap `[-180,180)`). `rotate_vectors`/`unrotate_vectors(u, v, lon_geo, lat_geo, R)` — tangent-vector maps; **take GEOGRAPHIC positions** (rotated images computed internally), magnitude-preserving. Pure vectorised numpy, run once per mesh load / snapshot — never in particle loops, no numba. Exact-pole basis is the limit at the stored longitude.
