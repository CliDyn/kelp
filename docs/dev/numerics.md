## numerics/interpolate.py — CRITICAL MODULE
Numba `@njit` with graceful Python fallback (pattern repeated across all numerics modules).

`_interp_leastsq_core` — per-particle least-squares fit over elements around the nearest node:
1. element IDs from `node_to_elems`;
2. metric scaling `z0 = cos(yp·DEG2RAD) · METERS_PER_DEG_LAT`;
3. **centered coordinates** `ex = lon_elem·z0 − xp_m`, `ey = lat_elem·METERS_PER_DEG_LAT − yp_m` — eliminates the catastrophic cancellation that the absolute-coordinate Sarrus determinant suffers (see docs/interpolation.md §1);
4. symmetric 3×3 normal matrix + RHS in one loop; Sarrus determinant + Cramer;
5. value at the particle is just `a0` (dx=dy=0 in centered coords).

- `_interp_leastsq_core_fortran` — legacy absolute-coordinate kernel, kept only for comparison (has the cancellation bug).
- `_interp_leastsq_core_tinterp` — blends two snapshots inline per element (used by fused time-aware RK kernels). `_interp_barycentric_core_tinterp` — the NODE-layout barycentric twin: same nested two-level blend per VERTEX on the untouched bary geometry (no elem_hint, node layout only; consumed by `_fused_rk{2,4}_step_2d_bary_tinterp`).
- `interp_leastsq(state, mesh, vel, nn_nodes, time_dir=1.0, layer=0)` — `prange` loop over alive particles; `layer` is `int` (2D) or per-particle `np.ndarray` (3D, via `_loop_interp_leastsq_3d`).
- `interp_nearest_element` — fallback: containing element's value.

**u/v registry** (`get_interpolator{,_single}(name, edge_leastsq_bc="freeslip")` → vectorised / single-particle; unknown name raises with the valid list): `"leastsq"` maps to the untouched `interp_leastsq{,_single}`, `"barycentric"` to `interp_barycentric{,_single}` (`_interp_barycentric_core`), `"edge_leastsq"` to `interp_edge_leastsq{,_single}` (`_interp_edge_leastsq_core`; non-default bc → functools.partial).
- `_interp_edge_leastsq_core` — containing element (`_find_containing_element_local`) + edge-sharing neighbors (`build_elem_neighbors`) → 4-point (tri) / 5-point (quad) LSQ plane fit, particle-centered metric coords with WRAPPED lon deltas (dateline-safe; the default leastsq cores got their own gated antimeridian correction in 2026-07); boundary edge → ghost = own centroid mirrored across the edge, value = mirror image `2(u·t̂)t̂ − u` (freeslip) / `−u_own` (noslip); element layout only (node → ValueError in the wrappers); containment required → ok=False. Linear-exact in interior elements; freeslip keeps WALL-PARALLEL constants exact at the coast and damps the normal component. **noslip artifacts (documented, characterization-pinned)**: interior-side overshoot ~+60% in wall elements, sign reversal near two-wall corners — single-plane-fit property, not a bug. Sliver stencils stay conditioned (mirror ghosts span both directions; det/(a11·a22·a33) ~ 0.7 even at aspect 1e-4) — no scale-aware det guard needed.
- `_interp_barycentric_core` — containing element (`_find_containing_element_local`) → `_polygon_weights` vertex blend; vertex values: node layout = direct lookup, element layout = area-weighted average over `node_to_elems` (`build_elem_areas`). Projects to the local plane around the **element centroid** (not particle-centered) using `mesh.r_earth` (threaded from the wrappers; weights are scale-invariant so the value is R-independent — the arg only keeps the projection unit-consistent with the mesh metrics). Constants exact both layouts; linear exact node-layout only (element layout smooths). Containment required → `ok=False` reverts to OUTSIDE.

- **Depth-linear u/v (2026-10; `uv_vertical` `"level"` / `"layer_linear"`, docs/vertical.md §2.1, docs/velocity_interpolation.md §7)**: only `interp_barycentric` evaluates such a field — it dispatches on `getattr(vel, "uv_vertical", "layer") != "layer"` to `_interp_barycentric_dl` (node layout required; then the record check `check_depth_linear_record` unless `is_checked`, BEFORE the `u.ndim` guard, so a `LazyLerpField` is checked through its parents before anything is blended; then `depth_points(mesh, placement)`) → `_loop_interp_bary_dl` (prange) → `_interp_barycentric_core_dl` (the node-layout geometry of `_interp_barycentric_core`, elem hint included; per vertex `uv_bracket(p, last[nd], z)` + `uv_at`; a NaN `z` is mapped to `+inf` = each vertex's last point, `find_layer`'s NaN outcome); the `layer` argument is ignored and every particle is read at `state.z`. Fused twins for the 3-D RK2 kernels: `_interp_barycentric_core_tinterp_dl` (per stored value `_tinterp_point_uv`: the layer twin's expressions and endpoint shortcuts, each value widened to float64 FIRST — without the widening a float32 numpy scalar would blend in float32 under `NUMBA_DISABLE_JIT` (NEP 50); compiled, the widening is exact) and `_interp_barycentric_core_pchip4_dl` (`_pchip_value_scalar` per stored value); both TIME first, then depth, then the vertex sum — bit for bit the unfused path. Every other entry refuses a depth-linear field before slicing anything (`_reject_depth_linear(vel, where, reason)`: `interp_leastsq`, `interp_edge_leastsq`, `interp_nearest_element` → "needs uv_interp='barycentric'"; the single-point entries `interp_{leastsq,barycentric,edge_leastsq}_single` → no depth argument, no single-point depth-linear API in this version).

## numerics/vertical_uv.py — depth-linear u/v: table, bracket, record check (2026-10)
- **Table** `depth_points(mesh, placement) → DepthPoints(p, last)` (frozen dataclass, `eq=False`: a token compared by identity; both arrays read-only): `p` float64 `(M,)` = `|mesh.sigma|` (`"level"`, `M = K`) or the layer centres (`"layer_linear"`, `M = K-1`); `last` int32 `(N,)` = `max(0, min(M-1, max({k: lower_k <= depth_i} ∪ {0}), D_i))`, `lower` = `p` (level) or `z[1:]` (layer: `find_layer`'s rule, a partial bottom layer is never read), `D_i` = `mesh.metadata["uv_data_last"]` (int `(N,)`, `>= -1`; `-1` = surface only, which must be finite; SNAPSHOT at first use — `_snapshot_declaration` makes an owned copy (`np.array(decl, copy=True)`, dtype kept) and freezes it before anyone else holds it, the copy is validated and built from, and the build installs it as `mesh.metadata["uv_data_last"]`, so the declaration in effect is exactly what the table was built from and no base array or earlier view of the reader's array can change it (freezing the reader's own array did not freeze its base or views); a snapshot already held by a live entry, e.g. the other placement's, is reused, not copied again; a write into the snapshot raises; an entry counts only while its snapshot is still read-only, so a copied or unpickled mesh — whose snapshot numpy returns writeable — gets a new snapshot, validated again, on first use; a shallow copy sharing `mesh.metadata` sees the snapshot too and rebuilds its own table from it once, same values). NaN depth → 0; `+inf` → `M-1` (then `D_i`); `-inf` → 0. Refuses `"layer"`/unknown placements, a non-z-level mesh, too few levels, a non-finite or decreasing level table (the message names the size and the first offending level, never the whole table), a wrong-shaped depth or declaration.
- **Cache** `mesh._uv_depth_points = {placement: _DepthPointsEntry(sigma, depth, decl, points)}` holding STRONG references; valid while `mesh.sigma`, `mesh.depth` and the declaration are the SAME objects (identity, never `id()`, which a freed object can pass on); copy-on-write (the dict is replaced, never mutated, so a shallow mesh copy — which shares the dict object — never sees the other's rebuild). In-place writes to those arrays are NOT detected: replace them.
- **Bracket** `uv_bracket(p, last_i, z) → (k, alpha)` (njit): clip to `[p[0], p[last_i]]`; `alpha = -1.0` = read point `k` directly (an end, exactly on a point — of two coincident points the deeper one, except at or above `p[0]`, which reads point 0 even when point 1 coincides with it —, or a spacing < 1e-12 m), else `0 < alpha < 1` between `k` and `k+1 <= last_i`. NaN `z` → `(last_i - 1, NaN)` when `last_i > 0` (pinned in `tests/test_vertical_uv.py`; the kernels never pass NaN — they map it to `+inf`). `uv_at(f, node, k, alpha)` never touches `f[k+1]` on a direct read; result float64.
- **Record check** `check_depth_linear_record(vel, mesh, *, record="")`: u/v shape `(M, N)` and finite at every point `<= last[i]` (the parallel `_first_nonfinite_per_node` scan, 64-column blocks walking contiguous row segments); points below `last` may hold anything; `w` is never checked. Refusal names component, value, node, point, depth and `record`. Success stamps `vel._dl_token = depth_points(...)`; a `LazyLerpField` is checked through `vel_a`/`vel_b` (each skipped when already checked) without blending, and gets the token only when both parents hold the identical object. `is_checked(vel, mesh)` = `vel._dl_token is depth_points(mesh, vel.uv_vertical)` (a never-stamped field answers False without building a table), so a field checked on another mesh or before a `max_levels` cut counts as unchecked.
- Callers of the check: the tracking cache marking (`tracking._mark_depth_linear`), the HEALPix reader (raw record, option on), the step entry (`integrators._check_depth_linear_entry`), the fused runners (`_fused_3d_dl_table`) and `_interp_barycentric_dl` — each skips a field already checked for the current table.

## numerics/vertical.py — z-level 3D utilities
- Layer detection/clamping: `find_layer`, `find_layers` (vectorized, per-particle), `clamp_depth` (surface/bottom clamp against per-node bottom depth).
- `interp_w_spatial(..., method, mesh)` — two-stage W interpolation: vertical linear interp per node first, then horizontal combine by one of 4 methods: `"nearest"` (nearest node only, Fortran-compatible), `"leastsq"` (**default**; planar fit on 1-ring neighbour nodes, centered metric coords), `"barycentric"` (walks the local 1-ring to find the containing element, blends vertex values; quads via Wachspress weights (tris classical barycentric)), `"idw"` (1/d² on 1-ring, exact at nodes).
- **Bottom-aware clamping** per neighbour: `z_eval = min(z_particle, node_bottom[neighbour])` — prevents blending below-bottom W from shallow neighbours.
- **Bracket precompute** (TODO 6.4, 2026-08): leastsq/idw compute the particle's vertical bracket ONCE (`_w_bracket` → `_w_at_bracket`, a bit-identical decomposition of `_interp_w_linear_single`) and reuse it for unclamped neighbours; clamped neighbours re-bracket at their bottom. Pinned against frozen pre-6.4 reference copies (test_w_spatial_interp.py); ~×1.2–1.4 at K=100, ~×1.1 at K=48 (run-to-run noise ±15%). Barycentric/nearest untouched.
- Int constants `W_NEAREST=0..W_IDW=3` for Numba dispatch; `_collect_neighbour_nodes` builds the 1-ring stencil (fixed-size 64 array, Numba-safe).
- **Dateline**: every barycentric projection origin (`_interp_w_barycentric_single` + tinterp/pchip4 twins, `vertical_sigma._bary_locate`, sampling) is `core.mesh._seam_safe_lon0` — the raw vertex mean (same summation, off-seam bit-identical) unless the raw span > 180°, then first vertex + mean wrapped offset (the `_project_to_local_xy` rule); the raw mean put a 2+2 seam quad 180° away → silent nearest-node fallback until 2026-09-24 (`tests/test_bary_seam.py`).
- Barycentric method on QUADS uses product-form Wachspress weights via `mesh._polygon_weights`, gated `n_valid == 4` — the tri path keeps the inline scalar blend (zero allocations; the gate is a PERFORMANCE contract enforced by benchmark, not by value tests — dispatcher and inline tri math are bit-equal). Same gate in vertical_sigma and sampling barycentric branches; the quad branch blends unconditionally (no sentinel/fall-through since 2026-07).

## numerics/vertical_sigma.py — sigma-coordinate 3D utilities (FESOM-C)
**Sigma-following W sampling (2026-09-23)**: leastsq/barycentric/idw evaluate every neighbour column at the particle's σ, `z_j = (z/H_p)·H_j`, `H_p` = column height interpolated at the particle by the same method (`_H_leastsq_single`/`_H_bary_single`/`_H_idw_single`, `_bary_locate`; exact for a linear bottom with leastsq/barycentric) — the old `min(z, H_j)` mixed σ levels on slopes; `nearest` and all fallbacks unchanged; `sigma_column_height(mesh, lons, lats, nn, eta, alive, method, Dmin)` is the vectorised `H_p` = the particle's column in the sigma step (`s = z/H_p`); `find_layers_sigma`/`clamp_depth_sigma` take `H_particle=` (the step passes `H_p`; default the nearest node's column), `_loop_az_kick_sigma` takes a per-particle column. Column geometry: `column_depth(depth, eta, Dmin)` → `H = depth + eta` clamped to `Dmin`; `sigma_interfaces_to_z(sigma_lev, H)` → physical interface depths `z = (1−sigma)·H`. Layer detection `find_layer_sigma`/`find_layers_sigma`, clamping `clamp_depth_sigma`, interface-based w_cart interpolation `interp_w_sigma_linear` + the same 4 horizontal methods (`interp_w_sigma_spatial`). Dispatch happens in integrators on `mesh.vertical_coord`; stage-time `eta` flows through `VelocityField.lerp`; the fused 3D Euler kernel is **bypassed** for sigma meshes.

## w_reconstruct.py — offline W reconstruction (FESOM2 z-level only)
- **Variant A (divergence)**: `w(D) = −ssh_t − ∫ div_h dz`, weak-form shape-function divergence (approximate); Tier 1 constant surface area, Tier 2 depth-dependent `nod_area` from mesh diag.
- **Variant B (ALE heuristic)**: `w_cart ≈ w_ALE − (1−D/H)·ssh_t` — heuristic, not exact z-star physics.
- Sign convention: **positive-down** (w > 0 = downwelling), KELP's internal one (FESOM2's own `w` output is positive UP — the readers negate it); `w_surf = −d(ssh)/dt`. `utils/reconstruct_w.py` stamps `positive="down"` on its output so `mode.w_positive: auto` passes it through (files written before 2026-09-23 need `w_positive: down`).
- Entry: `reconstruct_w(u, v, eta_prev, eta_next, dt_real, mesh, w_ale=None, mesh_extras=None, ...) → (K, N)` node-based at interfaces — same layout as `VelocityField.w`. `compare_variants(...)` gives cross-validation diagnostics. CLI: `utils/reconstruct_w.py` (YAML-driven, writes `.nc`/`.zarr` with the SOURCE u file's time coordinate — values + units/calendar encoding — so `data.ncinput_w` attaches by label; files written before 2026-10-04 carry relative seconds and are refused by the reader).

## numerics/diffusion.py — stochastic diffusion
**Counter-based RNG** — every draw is fully determined by `(seed, real_id, particle_i, step_i, component)`. No global RNG state → parallel-safe (any thread order is bit-identical) and restart-safe (resume from `step_i=N` reproduces the continuous run). **Trap**: `particle_i` must be the *original* ParticleState index, not the alive-mask compaction index. **Shards (2026-10-04)**: the key is `pid_offset + i` (`DiffusionStepArgs.pid_offset`, `BeachingStepArgs`/`BeachRunConfig.pid_offset`, every loop kernel's trailing `pid_offset` arg, default 0 = byte-identical) — `run_tracking` resolves it from `data.particle_offset` or the seed file's `# kelp particle_offset N` header (`core.release.read_particle_offset`; written by `utils/split_seeds.py`; mismatch, or an offset > 0 with `n_pulses > 1` → ValueError), `run_single_realization`/`track_particles` take `particle_offset=` (validated by `core.release.check_particle_offset`), the writer stamps attr `particle_offset`, `write_restart_file(particle_offset=)` stores it and `load_restart` returns it (a chain driver passes it on), `utils/concat_trajectories.py` refuses shards whose offsets do not follow the merge order unless every shard stamps `random_draws = 0` (run_single_realization stamps it; then it only warns), `utils/split_seeds.py` offsets a re-split shard by its own header and refuses to overwrite existing shard files, and `utils/sort_seeds.py` refuses a shard file; `concat_trajectories(independent_shards=True)` / `--independent-shards` merges shards that are independent by design (pulsed restart-split, own seeds) — refuses shards that share any one seed of a random feature they use (diffusion; stochastic beaching/resuspension) over overlapping indices, warns when seeds are unrecorded; stochastic shards without any `particle_offset` (older engine) merge with a warning; stamps `independent_shards = 1` + `shard_counts`/`shard_particle_offsets`/`shard_seeds` and drops the scalar offset/seeds; the splitter's cleanup removes only exact `seeds_shardNNN.dat` names and never the input (compared with `os.path.samefile`; targets are unlinked before writing, never written through a link); any comment before the data that mentions `particle_offset`/`particle-offset` (or starts `kelp particle offset`) must be the exact header with ASCII digits (near misses refused, also by the utils' standalone fallbacks). Integrators: the all-dead early exit returns zero `u/v/w` (`_zero_dead_velocity`), like the kernels — a fully dead shard recorded stale velocities before (output format 2 records those as NaN via `mask_inactive_velocity`). Primitives: `_splitmix64`, `_philox_uint64` (order-sensitive 5-key hash; despite the name a keyed SplitMix64 chain, NOT Philox — name kept for seeding-contract stability), `_normal_pair` (Box-Muller pair from one 64-bit hash), `_standard_normal`, `COMP_HORIZONTAL = 0`.

**Scheme kernels** (pure-metres displacement; signed `dt` for the ADVECTION only, `|dt|` for the ∂K drift, the Milstein term and the noise — since 2026-09-23 the backward process is the adjoint `−u + ∇K`; the old signed drift gave a backward density ∝ K⁻²): `diffusion_uniform_step_meters` (Brownian kick, split mode), `diffusion_em_step_meters` (Euler-Maruyama with Itô drift correction), `diffusion_m1_step_meters` (Milstein; on spatially-varying Kh the integrator layer (`integrators._maybe_warn_m1_variable_kh`, keyed `(seed, real_id, scheme)` since 2026-10-04 — the old array-id key re-warned every temporal-interp step) emits a one-time-per-realization RuntimeWarning — cross-derivative iterated-integral terms not implemented, separable-Kh limitation; em is safer for general 2-D Kh).

**Kh interpolation + gradient** (node- or element-layout): `_kh_lsq_node_planar`/`_kh_lsq_elem_planar` (LSQ plane fit on the 1-ring → value + gradient), `_kh_value_at_xy` (rejects off-mesh queries via containment check), `_kh_gradient_at_xy` (central diff at `±dres_m` with fallback chain central → one-sided → LSQ analytic gradient → ok=False). Public wrappers `kh_value_at_point`/`kh_gradient_at_point` for tests.

**Loop kernels**: `_fill_uniform_kicks` (split-mode uniform), `_loop_em_combined_2d` (combined Euler+EM/M1, 2D only), `_loop_em_split_rk_2d` (split-RK kick; separate eval/apply position arrays so Kh can be sampled at start or end of step).

**Vertical Az (TODO 2.2b)**: `COMP_VERTICAL=1` claims the reserved slot; `diffusion_az_step_meters` (EM increment, Itô drift `+∂Az/∂depth` — sign survives the z-up→depth flip; |dt| for drift AND noise since 2026-09-23 — backward keeps the drift); `reflect_depth` (specular modulo fold into [top,bot], multi-bounce, degenerate→top — NEVER clamp: clamping breaks the well-mixed condition); `az_column_value_gradient` (nearest-node column, linear between interfaces, bottom-aware; gradient = slope of the SAME segment, the segment above on an interface — since 2026-09-23; the old half-layer central difference broke the well-mixed generator on non-linear profiles); loop kernels `_loop_az_kick_zlevel` (const+field) / `_loop_az_kick_sigma` (const only, v1) — fold bounds mirror `clamp_depth`/`clamp_depth_sigma` exactly. Headline test: well-mixed condition (uniform stays uniform in 10× nonuniform Az; drift-free walk would give p∝1/Az).

**Kicks on the sphere (2026-09-23)**: every horizontal kick (split uniform, combined EM/M1, split-RK) moves along the GREAT CIRCLE (`sphere_displace` / `sphere_displace_arrays`, exponential map, R = METERS_PER_DEG_LAT/DEG2RAD) instead of the lon/lat chart (which lacked the metric drift −K tanφ/R); `anisotropic_metric_drift_m` adds (Kx−Ky)tanφ/R|dt| northward for Kx≠Ky (lat capped 89.9°); combined EM: diffusive part via the exp map from the start, advection keeps the chart step. Pinned by `tests/test_spherical_random_walk.py` (generator of sin φ, pole crossing).

`DiffusionStepArgs` NamedTuple — what integrators consume: scheme, scalar Kh, seed, real_id, step_i, composition, dres_m, kh_eval_position, az_enabled, az_const, az_requires_field (az field itself rides `vel.az`; requires_field=True → payload without `.az` raises).

## numerics/beaching.py — beaching criteria + resuspension (TODO 2.2)

## numerics/sampling.py — scalar field sampling (TODO 2.4)
- `sample_field(values, mesh, lons, lats, zs=None, *, nearest=None, alive=None, eta=None, method="leastsq") → (P,) float64` — shapes `(N,)` (horizontal only), `(K-1, N)` mid-layer (vertical linear between midpoints, clamped, bottom-aware per neighbour), `(K, N)` interface (delegates to `interp_w_spatial`/`interp_w_sigma_spatial` with **`time_dir=+1.0` hardcoded** — W kernels bake the integration sign, scalars are direction-free; backward == forward, mutation-pinned).
- 4 horizontal methods over the nearest-node 1-ring with W fallback semantics (local failure → nearest value, never NaN); NaN only for dead particles, `nearest < 0`, or a genuinely-fill nearest value. **Non-finite neighbours are FILTERED from the stencils** (2026-08: leastsq skips + needs ≥3 finite, idw skips, barycentric NaN-vertex → nearest fallback; all-finite path bit-identical) — one coastal fill value no longer poisons the sample. `nearest=None` → computed via `find_nearest_nodes`. Sigma meshes require `eta` (column geometry) and take `Dmin=` (the run's `numerics.Dmin`, passed by `_sample_record_fields`; was a hard-coded 0.5 m until 2026-09-24); the sigma mid-layer `min(z, H)` clamp is mathematically shadowed by the last-midpoint clamp (defensive only).
- `_combine_horizontal` deliberately re-implements idw/leastsq/bary: vertical.py's per-method helpers fuse vertical interp + `time_dir` and can't serve direction-free scalars.
