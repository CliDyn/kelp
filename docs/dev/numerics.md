## numerics/interpolate.py — CRITICAL MODULE
Numba `@njit` with graceful Python fallback (pattern repeated across all numerics modules).

`_interp_leastsq_core` — per-particle least-squares fit over elements around the nearest node:
1. element IDs from `node_to_elems`;
2. metric scaling `z0 = cos(yp·DEG2RAD) · METERS_PER_DEG_LAT`;
3. **centered coordinates** `ex = lon_elem·z0 − xp_m`, `ey = lat_elem·METERS_PER_DEG_LAT − yp_m` — eliminates the catastrophic cancellation that the absolute-coordinate Sarrus determinant suffers (see docs/interpolation.md §1);
4. symmetric 3×3 normal matrix + RHS in one loop; Sarrus determinant + Cramer;
5. value at the particle is just `a0` (dx=dy=0 in centered coords).

- `_interp_leastsq_core_fortran` — legacy absolute-coordinate kernel, kept only for comparison (has the cancellation bug).
- `_interp_leastsq_core_tinterp` — blends two snapshots inline per element (used by fused time-aware RK kernels). `_interp_barycentric_core_tinterp` — the NODE-layout barycentric twin: same nested two-level blend per VERTEX on the untouched bary geometry (no elem_hint, node layout only; consumed by `_fused_rk{2,4}_step_2d_bary_tinterp`).
- `interp_leastsq(state, mesh, vel, nn_nodes, time_dir=1.0, layer=0)` — `prange` loop over alive particles; `layer` is `int` (2D) or per-particle `np.ndarray` (3D, via `_loop_interp_leastsq_3d`).
- `interp_nearest_element` — fallback: containing element's value.

**u/v registry** (`get_interpolator{,_single}(name, edge_leastsq_bc="freeslip")` → vectorised / single-particle; unknown name raises with the valid list): `"leastsq"` maps to the untouched `interp_leastsq{,_single}`, `"barycentric"` to `interp_barycentric{,_single}` (`_interp_barycentric_core`), `"edge_leastsq"` to `interp_edge_leastsq{,_single}` (`_interp_edge_leastsq_core`; non-default bc → functools.partial).
- `_interp_edge_leastsq_core` — containing element (`_find_containing_element_local`) + edge-sharing neighbors (`build_elem_neighbors`) → 4-point (tri) / 5-point (quad) LSQ plane fit, particle-centered metric coords with WRAPPED lon deltas (dateline-safe; the default leastsq cores got their own gated antimeridian correction in 2026-07); boundary edge → ghost = own centroid mirrored across the edge, value = mirror image `2(u·t̂)t̂ − u` (freeslip) / `−u_own` (noslip); element layout only (node → ValueError in the wrappers); containment required → ok=False. Linear-exact in interior elements; freeslip keeps WALL-PARALLEL constants exact at the coast and damps the normal component. **noslip artifacts (documented, characterization-pinned)**: interior-side overshoot ~+60% in wall elements, sign reversal near two-wall corners — single-plane-fit property, not a bug. Sliver stencils stay conditioned (mirror ghosts span both directions; det/(a11·a22·a33) ~ 0.7 even at aspect 1e-4) — no scale-aware det guard needed.
- `_interp_barycentric_core` — containing element (`_find_containing_element_local`) → `_polygon_weights` vertex blend; vertex values: node layout = direct lookup, element layout = area-weighted average over `node_to_elems` (`build_elem_areas`). Projects to the local plane around the **element centroid** (not particle-centered) using `mesh.r_earth` (threaded from the wrappers; weights are scale-invariant so the value is R-independent — the arg only keeps the projection unit-consistent with the mesh metrics). Constants exact both layouts; linear exact node-layout only (element layout smooths). Containment required → `ok=False` reverts to OUTSIDE.

- **Depth-linear u/v (2026-10; `uv_vertical` `"level"` / `"layer_linear"`, docs/vertical.md §2.1, docs/velocity_interpolation.md §7)**: the vectorised interpolators dispatch on `getattr(vel, "uv_vertical", "layer") != "layer"` and read every particle at `state.z` (the `layer` argument is ignored); each runs the record check `check_depth_linear_record` unless `is_checked`, BEFORE the `u.ndim` guard (a `LazyLerpField` is checked through its parents before anything is blended), then takes `depth_points(mesh, placement, layout)`. A NaN `z` is mapped to `+inf` (`find_layer`'s NaN outcome): dry wherever the bed is finite. Walls at depth: a member is wet while `uv_wet(bed, c, z)` (`z <= bed[c]`, the table's physical bed); every member wet = the layer core's arithmetic on the depth-linear values (an all-wet singular fit stays `ok=False`); otherwise the dry members are left out, and the fallbacks run only when at least one member is dry.
  - *Node layout* (`barycentric` only): `interp_barycentric` → `_interp_barycentric_dl` → `_loop_interp_bary_dl` (prange) → `_interp_barycentric_core_dl` (the node-layout geometry of `_interp_barycentric_core`, elem hint included; per vertex `uv_bracket(p, last[nd], z)` + `uv_at`). `_dl_node_wall(w, verts, nv, bed, zq) → (n_wet, den, k_deep)`: all wet → the plain sum; some dry → divide by the wet weights' sum, or (sum < 1e-12) set the wet weights to 1.0 IN `w` and divide by `n_wet` (equal-weight mean); none wet → `k_deep`, the vertex with the largest bed (first on ties), read at `last[nd]`. Fused twins for the 3-D RK2 kernels: `_interp_barycentric_core_tinterp_dl` (per stored value `_tinterp_point_uv`: the layer twin's expressions and endpoint shortcuts, each value widened to float64 FIRST — without the widening a float32 numpy scalar would blend in float32 under `NUMBA_DISABLE_JIT` (NEP 50); compiled, the widening is exact) and `_interp_barycentric_core_pchip4_dl` (`_pchip_value_scalar` per stored value); both TIME first, then depth (the depth blend written in line, not through `uv_at`), then `_dl_node_wall` and the vertex sum — a dry vertex is never blended in time — bit for bit the unfused path.
  - *Element layout* (`"layer_linear"`, `leastsq` / `edge_leastsq` / `barycentric`; the element table needs `mesh.metadata["uv_data_last_elem"]` and `["elem_bed"]`; areas `build_elem_areas`): `interp_leastsq` → `_interp_leastsq_dl` → `_loop_interp_leastsq_3d_dl` → `_interp_leastsq_core_dl` (the plane fit over the nearest node's ring with the dry elements skipped; fewer than 3 wet with one dry, or a singular fit with one dry → the wet area mean; none wet → `_find_containing_element_local`, searched in that case only, outside → `ok=False`); `interp_edge_leastsq` → `_interp_edge_leastsq_dl` → `_loop_interp_edge_lsq_3d_dl` → `_interp_edge_leastsq_core_dl` (a dry edge neighbour → `nb = -1`, the boundary ghost of the bc, `n_dry` counted; singular with `n_dry > 0` → the area mean of the own element and its neighbours, wet only; the own element dry → the area mean of its wet neighbours, no ghosts, none wet → the own element at its last point); `interp_barycentric` → `_interp_barycentric_dl` → `_loop_interp_bary_elem_dl` → `_interp_bary_elem_core_dl` (per vertex the wet-element area mean with `time_dir` 1.0 — the layer kernel applies `time_dir` to the sum; a vertex without a wet element is left out and the weights renormalised, equal-weight mean below 1e-12; wet elements whose areas sum ≤ 0 → `ok=False`, as the layer kernel; no vertex left → the containing element, dry too, at its last point). The shared fallback is `_dl_elem_wet_mean(members, n, zq, own, time_dir, p, last, bed, elem_areas, u_f, v_f) → (U, V, ok)`: `time_dir · Σ A_e u_e / Σ A_e` over the wet `members[:n]` in the given order (entries `< 0` skipped); none wet → element `own` read with `uv_bracket(p, last[own], zq)` (its last point when dry; at `zq` when the 2-ring search found it outside the ring and wet), `own < 0` → `ok=False`; wet areas summing ≤ 0 → `ok=False`. `edge_leastsq` and element `barycentric` take `elems=` (the edge walk's pre-validated elements) like the layer wrappers.
  - *Refusals* (before slicing anything; `_reject_depth_linear(vel, where, reason)`): `interp_leastsq` / `interp_edge_leastsq` on a node-layout depth-linear field (`_DL_LAYOUT`: "on node layout … needs uv_interp='barycentric'"; a field without `uv_layout` counts as element layout, the `VelocityField` default); `interp_barycentric` on a layout other than node or element; `interp_nearest_element` on any depth-linear field ("needs uv_interp='barycentric'"); the single-point entries `interp_{leastsq,barycentric,edge_leastsq}_single` → no depth argument, no single-point depth-linear API in this version.
  - **Change both together** (duplicated on purpose, so that no layer `@njit` body changed and layer runs keep their bits): the plane fit of `_interp_leastsq_core` and `_interp_leastsq_core_dl`; the edge fit (ghosts, sums, guard) of `_interp_edge_leastsq_core` and `_interp_edge_leastsq_core_dl`; the containment and projection block of `_interp_barycentric_core` and of `_interp_barycentric_core_dl` (node) and `_interp_bary_elem_core_dl` (element); the depth blend `(1 − α)·a + α·b` of `vertical_uv.uv_at` and its in-line copies in `_interp_barycentric_core_tinterp_dl` / `_interp_barycentric_core_pchip4_dl` (the cores of the fused node RK2 twins `_fused_rk2_step_3d_bary_tinterp_dl` / `_fused_rk2_step_3d_bary_pchip_dl`); and the kernel pair `_fused_euler_step_3d` / `_fused_euler_step_3d_dl` ([integrators.md](integrators.md)). Guards: the bitwise all-wet tests at data points (`tests/test_interp_depth_linear.py`, `tests/test_interp_depth_linear_elements.py`, `tests/test_depth_linear_analytic.py::test_depth_constant_same_as_layer`) and fused == unfused (`tests/test_integrators_depth_linear_elements.py::test_fused_euler_equals_unfused`, `tests/test_fused_3d_depth_linear.py`) — an edit to one copy only shows there, not in the layer goldens.

## numerics/vertical_uv.py — depth-linear u/v: table, bracket, record check (2026-10)
- **Table** `depth_points(mesh, placement, layout="node") → DepthPoints(p, last, bed)` (frozen dataclass, `eq=False`: a token compared by identity; all three arrays read-only; one column per node, or per element with `layout="element"`): `p` float64 `(M,)` = `|mesh.sigma|` (`"level"`, `M = K`) or the layer centres (`"layer_linear"`, `M = K-1`); `bed` float64 `(C,)` = a copy of the physical bed (`mesh.depth`; elements `mesh.metadata["elem_bed"]`), never cut by `max_levels`; node `last` int32 `(N,)` = `max(0, min(M-1, max({k: lower_k <= depth_i} ∪ {0}), D_i))`, `lower` = `p` (level) or `z[1:]` (layer: `find_layer`'s rule, a partial bottom layer is never read), `D_i` = `mesh.metadata["uv_data_last"]` (int `(N,)`, `>= -1`; `-1` = surface only, which must be finite; SNAPSHOT at first use — `_snapshot_declaration` makes an owned copy (`np.array(decl, copy=True)`, dtype kept) and freezes it before anyone else holds it, the copy is validated and built from, and the build installs it as `mesh.metadata["uv_data_last"]`, so the declaration in effect is exactly what the table was built from and no base array or earlier view of the reader's array can change it (freezing the reader's own array did not freeze its base or views); a snapshot the engine made and that is still read-only — the other placement's, or a shallow copy's of the same mesh — is reused, not copied again (module-level `_SNAPSHOTS`, a `weakref.WeakValueDictionary` by `id`: a freed snapshot drops out, so a reused id never matches); a write into the snapshot raises; an entry counts only while its snapshot is still read-only, so a copied or unpickled mesh — whose snapshot numpy returns writeable — gets a new snapshot, validated again, on first use; a shallow copy sharing `mesh.metadata` sees the snapshot too and rebuilds its own table from it once, same values). NaN depth → 0; `+inf` → `M-1` (then `D_i`); `-inf` → 0. Element `last` int32 `(E,)` = `max(0, min(M-1, D_e))`, `D_e` = `mesh.metadata["uv_data_last_elem"]` (int `(E,)`, `>= -1`, the FESOM2 reader's declaration from `nlevels` / `zbar_e_bottom`, geometric already — no bathymetry rule; snapshotted exactly like the node declaration and installed back under its own key). Refuses `"layer"`/unknown placements, an unknown layout, `"level"` on element layout, a non-z-level mesh, too few levels, a non-finite or decreasing level table (the message names the size and the first offending level, never the whole table), a wrong-shaped depth, element bed or declaration, and an element table without the declaration or `elem_bed` (`_missing_elem_bottoms`: names both keys, `nlevels`/`zbar_e_bottom` and `mesh.metadata["meshpath"]`).
- **Cache** `mesh._uv_depth_points = {(placement, layout): _DepthPointsEntry(sigma, depth, decl, points)}` holding STRONG references (`depth` = the bed array the table was built from: `mesh.depth`, or `mesh.metadata["elem_bed"]`); valid while `mesh.sigma`, that bed array and the layout's declaration are the SAME objects — the node and the element table are independent (a new `mesh.depth` rebuilds only the node table, a new `elem_bed` only the element table) (identity, never `id()`, which a freed object can pass on); copy-on-write (the dict is replaced, never mutated, so a shallow mesh copy — which shares the dict object — never sees the other's rebuild). In-place writes to those arrays are NOT detected: replace them.
- **Bracket** `uv_bracket(p, last_i, z) → (k, alpha)` (njit): clip to `[p[0], p[last_i]]`; `alpha = -1.0` = read point `k` directly (an end, exactly on a point — of two coincident points the deeper one, except at or above `p[0]`, which reads point 0 even when point 1 coincides with it —, or a spacing < 1e-12 m), else `0 < alpha < 1` between `k` and `k+1 <= last_i`. NaN `z` → `(last_i - 1, NaN)` when `last_i > 0` (pinned in `tests/test_vertical_uv.py`; the kernels never pass NaN — they map it to `+inf`). `uv_at(f, node, k, alpha)` (any column: node or element) never touches `f[k+1]` on a direct read; result float64, `(1 − alpha)·a + alpha·b` (the form the in-line copies repeat: *Change both together* in the interpolate.py section above). `uv_wet(bed, col, z)` (njit) = `z <= bed[col]`: wet down to and including the bed; a NaN `z` or bed → dry; an infinite bed is wet at every depth (the kernels map a NaN particle depth to `+inf` before the test).
- **Record check** `check_depth_linear_record(vel, mesh, *, record="")`: dispatches on the field's layout (`_layout_of(vel)` = `vel.uv_layout`, a field-like object without one counts as element layout — the `VelocityField` default; the HEALPix raw-record namespace states `uv_layout="node"`): u/v shape `(M, C)` against the node or the element table and finite at every point `<= last[c]` (the parallel `_first_nonfinite_per_node` scan over columns, 64-column blocks walking contiguous row segments); points below `last` may hold anything; `w` is never checked. Refusal names component, value, node or element, point, depth and `record`. Success stamps `vel._dl_token = depth_points(...)`; a `LazyLerpField` is checked through `vel_a`/`vel_b` (each skipped when already checked) without blending, and gets the token only when both parents hold the identical object. `is_checked(vel, mesh)` = `vel._dl_token is depth_points(mesh, vel.uv_vertical, _layout_of(vel))` (a never-stamped field answers False without building a table), so a field checked on another mesh or before a `max_levels` cut counts as unchecked.
- Callers of the check: the tracking cache marking (`tracking._mark_depth_linear`), the HEALPix reader (raw record, option on), the step entry (`integrators._check_depth_linear_entry`), the fused runners (`_fused_3d_dl_table`: the node RK2 runners and, through `_fused_euler_3d_dl_table`, the element Euler runner) and the interpolator routes `_interp_barycentric_dl`, `_interp_leastsq_dl`, `_interp_edge_leastsq_dl` — each skips a field already checked for the current table.

## numerics/vertical.py — z-level 3D utilities
- Layer detection/clamping: `find_layer`, `find_layers` (vectorized, per-particle), `clamp_depth` (surface/bottom clamp against per-node bottom depth).
- `interp_w_spatial(..., method, mesh)` — two-stage W interpolation: vertical linear interp per node first, then horizontal combine by one of 4 methods: `"nearest"` (nearest node only, Fortran-compatible), `"leastsq"` (**default**; planar fit on 1-ring neighbour nodes, centered metric coords), `"barycentric"` (walks the local 1-ring to find the containing element, blends vertex values; quads via Wachspress weights (tris classical barycentric)), `"idw"` (1/d² on 1-ring, exact at nodes).
- **Bottom-aware clamping** per neighbour: `z_eval = min(z_particle, node_bottom[neighbour])` — prevents blending below-bottom W from shallow neighbours.
- **Bracket precompute** (TODO 6.4, 2026-08): leastsq/idw compute the particle's vertical bracket ONCE (`_w_bracket` → `_w_at_bracket`, a bit-identical decomposition of `_interp_w_linear_single`) and reuse it for unclamped neighbours; clamped neighbours re-bracket at their bottom. Pinned against frozen pre-6.4 reference copies (test_w_spatial_interp.py); ~×1.2–1.4 at K=100, ~×1.1 at K=48 (run-to-run noise ±15%). Barycentric/nearest untouched.
- Int constants `W_NEAREST=0..W_IDW=3` for Numba dispatch; `_collect_neighbour_nodes` builds the 1-ring stencil (fixed-size 64 array, Numba-safe).
- **Dateline**: every barycentric projection origin (`_interp_w_barycentric_single` + tinterp/pchip4 twins, `vertical_sigma._bary_locate`, sampling) is `core.mesh._seam_safe_lon0` — the raw vertex mean (same summation, off-seam bit-identical) unless the raw span > 180°, then first vertex + mean wrapped offset (the `_project_to_local_xy` rule); the raw mean put a 2+2 seam quad 180° away → silent nearest-node fallback until 2026-09-24 (`tests/test_bary_seam.py`).
- Barycentric method on QUADS uses product-form Wachspress weights via `mesh._polygon_weights`, gated `n_valid == 4` — the tri path keeps the inline scalar blend (zero allocations; the gate is a PERFORMANCE contract enforced by benchmark, not by value tests — dispatcher and inline tri math are bit-equal). Same gate in vertical_sigma and sampling barycentric branches; the quad branch blends unconditionally (no sentinel/fall-through since 2026-07).

## numerics/vertical_sigma.py — sigma-coordinate 3D utilities (FESOM-C)
**Sigma-following W sampling (2026-09-23)**: leastsq/barycentric/idw evaluate every neighbour column at the particle's σ, `z_j = (z/H_p)·H_j`, `H_p` = column height interpolated at the particle by the same method (`_H_leastsq_single`/`_H_bary_single`/`_H_idw_single`, `_bary_locate`; exact for a linear bottom with leastsq/barycentric) — the old `min(z, H_j)` mixed σ levels on slopes; `nearest` and all fallbacks unchanged; `sigma_column_height(mesh, lons, lats, nn, eta, alive, method, Dmin)` is the vectorised `H_p` = the particle's column in the sigma step (`s = z/H_p`); `find_layers_sigma`/`clamp_depth_sigma` take `H_particle=` (the step passes `H_p`; default the nearest node's column), `_loop_az_kick_sigma` takes a per-particle column. Column geometry: `column_depth(depth, eta, Dmin)` → `H = depth + eta` clamped to `Dmin`; `sigma_interfaces_to_z(sigma_lev, H)` → physical interface depths `z = (1−sigma)·H`. Layer detection `find_layer_sigma`/`find_layers_sigma`, clamping `clamp_depth_sigma`, interface-based w_cart interpolation `interp_w_sigma_linear` + the same 4 horizontal methods (`interp_w_sigma_spatial`). Dispatch happens in integrators on `mesh.vertical_coord`; stage-time `eta` flows through `VelocityField.lerp`; the fused 3D Euler kernel is **bypassed** for sigma meshes.

## w_reconstruct.py — offline W reconstruction (FESOM2 z-level only)
- **Variant A (divergence)**: `w(D) = −ssh_t − ∫ div_h dz`, weak-form shape-function divergence (approximate); Tier 1 constant surface area, Tier 2 depth-dependent `nod_area` from mesh diag.
- **Variant B (ALE heuristic)**: `w_cart ≈ w_ALE − (1−D/H)·ssh_t` — heuristic, not exact z-star physics.
- Sign convention: **positive-down** (w > 0 = downwelling), KELP's internal one (FESOM2's own `w` output is positive UP — the readers negate it); `w_surf = −d(ssh)/dt`. `utils/reconstruct_w.py` stamps `positive="down"` on its output so `mode.w_positive: auto` passes it through (files written before 2026-09-23 need `w_positive: down`).
- **Layer data only** (2026-10): `require_layer_data(mesh, uv_vertical="layer")` refuses a FESOM 1.4 mesh (`"fesom14_source"` in `mesh.metadata`; u/v on the levels, and its output holds `wo` itself) and `uv_vertical == "level"` with a `ValueError` naming the fix (track with the model's `wo`); `"layer"` and `"layer_linear"` pass. Called first by `reconstruct_w`, `compute_divergence_approx` and `compute_divergence_with_area`, which take a keyword-only `uv_vertical=` (default `"layer"`: existing callers unchanged). `utils/reconstruct_w.py` refuses the same inputs before loading anything (`_refuse_level_inputs`: a `source.meshpath` holding `nod3d.out`; a `source.u_path` whose u variable (`u`/`ua`/`u_vel`/`uo`) is a `(time, nodes_3d)` vector or level-wise on a level axis starting at 0 m — layer centres never lie at the surface).
- Entry: `reconstruct_w(u, v, eta_prev, eta_next, dt_real, mesh, w_ale=None, mesh_extras=None, ...) → (K, N)` node-based at interfaces — same layout as `VelocityField.w`. `compare_variants(...)` gives cross-validation diagnostics. CLI: `utils/reconstruct_w.py` (YAML-driven, writes `.nc`/`.zarr` with the SOURCE u file's time coordinate — values + units/calendar encoding — so `data.ncinput_w` attaches by label; files written before 2026-10-04 carry relative seconds and are refused by the reader).

## numerics/diffusion.py — stochastic diffusion
**Counter-based RNG** — every draw is fully determined by `(seed, real_id, particle_i, step_i, component)`. No global RNG state → parallel-safe (any thread order is bit-identical) and restart-safe (resume from `step_i=N` reproduces the continuous run). **Trap**: `particle_i` must be the *original* ParticleState index, not the alive-mask compaction index. **Shards (2026-10-04)**: the key is `pid_offset + i` (`DiffusionStepArgs.pid_offset`, `BeachingStepArgs`/`BeachRunConfig.pid_offset`, every loop kernel's trailing `pid_offset` arg, default 0 = byte-identical) — `run_tracking` resolves it from `data.particle_offset` or the seed file's `# kelp particle_offset N` header (`core.release.read_particle_offset`; written by `utils/split_seeds.py`; mismatch, or an offset > 0 with `n_pulses > 1` → ValueError), `run_single_realization`/`track_particles` take `particle_offset=` (validated by `core.release.check_particle_offset`), the writer stamps attr `particle_offset`, `write_restart_file(particle_offset=)` stores it and `load_restart` returns it (a chain driver passes it on), `utils/concat_trajectories.py` refuses shards whose offsets do not follow the merge order unless every shard stamps `random_draws = 0` (run_single_realization stamps it; then it only warns), `utils/split_seeds.py` offsets a re-split shard by its own header and refuses to overwrite existing shard files, and `utils/sort_seeds.py` refuses a shard file; `concat_trajectories(independent_shards=True)` / `--independent-shards` merges shards that are independent by design (pulsed restart-split, own seeds) — refuses shards that share any one seed of a random feature they use (diffusion; stochastic beaching/resuspension) over overlapping indices, warns when seeds are unrecorded; stochastic shards without any `particle_offset` (older engine) merge with a warning; stamps `independent_shards = 1` + `shard_counts`/`shard_particle_offsets`/`shard_seeds` and drops the scalar offset/seeds; the splitter's cleanup removes only exact `seeds_shardNNN.dat` names and never the input (compared with `os.path.samefile`; targets are unlinked before writing, never written through a link); any comment before the data that mentions `particle_offset`/`particle-offset` (or starts `kelp particle offset`) must be the exact header with ASCII digits (near misses refused, also by the utils' standalone fallbacks).
